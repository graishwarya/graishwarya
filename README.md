# graishwarya.github.io — Build • Learn • Grow

Your customized Jekyll + GitHub Pages learning blog starter.

## Publish this blog

1. In GitHub, create a **Public** repository named exactly `graishwarya.github.io`.
2. Upload the contents of this folder into the repository root (do not upload the ZIP file).
3. Go to **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**; choose branch `main` and folder `/ (root)`, then Save.
5. Wait for the deployment. Blog URL: https://graishwarya.github.io

Your profile remains https://github.com/graishwarya. The blog is a separate GitHub Pages website linked from your profile README.

## Add an article

Create a Markdown file under `_posts` named `YYYY-MM-DD-your-title.md`, with front matter:

```yaml
---
layout: post
title: "Your article title"
date: YYYY-MM-DD
category: Product
excerpt: "Short card description."
---
```

Write the article in Markdown and commit to `main`. The homepage automatically lists newest posts using the same visual theme.
